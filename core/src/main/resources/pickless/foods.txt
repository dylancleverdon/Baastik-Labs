# Pickless food knowledge: foods, label ingredients and dishes.

# FODMAP thresholds are ESTIMATES compiled from published research and public dietitian guidance
# (not copied from any app's database). The app always labels them as estimates.
#
# Columns (| separated):
#   id | kind | category | name | aliases | parent | tags | fodmap | units | components
# kind:       F = food (searchable), I = label ingredient (not searched), D = dish (searchable)
# aliases:    comma-separated phrases matched in ingredient lists and used by search (lowercase)
# parent:     inherits the parent's tags (not its FODMAP numbers)
# tags:       avoid categories / families. "whole" = when a product's name matches, its FODMAP
#             numbers describe the whole product (milks, breads...). maybe-* = could contain it.
# fodmap:     group:low/moderate in grams of this food per serve. Up to "low" is green, up to
#             "moderate" is amber, beyond is red. Groups: fructans gos lactose fructose sorbitol mannitol
# units:      name=grams; the first is the default serving
# components: for dishes, typical recipe per default serving: id:grams;...
#
# IDs are permanent: never rename or reuse one (logs refer to them).
