# Setting up Pickless (once)

## 1. Install it on your Samsung phone

1. On the phone, open **github.com/dylancleverdon/Baastik-Labs/releases** and find the newest
   **Pickless** release (`pickless-v…`). Tap the `Pickless-….apk` file to download it.
2. Open the download. Android asks whether your browser may install apps: tap **Settings**, turn on
   **Allow from this source**, go back, and tap **Install**.
3. If you see **"Blocked by Auto Blocker"**: Settings > Security and privacy > **Auto Blocker** > off.
   (You can turn it back on after the first install, but then updates can't install themselves.)
4. If Play Protect says the app is unrecognized: tap **More details > Install anyway**. It's your
   own app, signed by this repo.

## 2. Let it update itself

Pickless checks for a new version every hour. The first time one arrives, Android asks you to allow
Pickless to install apps: turn on **Allow from this source**. After that, updates install by
themselves (on older Android versions you tap **Install** on a notification).

## 3. First run

The setup is pre-filled: avoid list (dairy, oats, soy, fried, spicy, Brussels sprouts), "bad BMs are
mostly loose", nicotine in the check-in, evening reminder. Tell it how long you've been avoiding
those foods so the coach knows when a test is due.

## 4. Optional extras

- **Brave Search key** (for foods Pickless doesn't know): Settings > Looking up unknown foods. Paste
  it there, not anywhere else. Lookups are capped (300 a month by default), well inside Brave's
  $5 monthly credit.
- **Suggestion box**: connect your "elimination diet app suggestion sheet" by following
  [suggestions/README.md](../suggestions/README.md) on your computer, then scanning the QR code it
  shows from More > Suggestion box.
- **Health Connect**: Settings > Health Connect, to pre-fill sleep, exercise and period days from
  a watch or fitness app.
- **Home-screen widget**: long-press the home screen > Widgets > Pickless.

## 5. Sometime in 2027

Google is rolling out developer registration for sideloaded apps (it reaches the US in 2027). When it
does, Pickless will need a free one-time "limited distribution" registration (no ID, up to 20
devices). Until then nothing is needed.
